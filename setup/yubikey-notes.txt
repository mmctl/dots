- Disable all unused protocols, both on USB and NFC.
  Enable: FIDO2, U2F, PIV

  Disable with:
  ykman config usb --disable oath
  ykman config usb --disable otp
  ykman config usb --disable openpgp
  ykman config usb --disable hsmauth
  ykman config nfc --disable oath
  ykman config nfc --disable otp
  ykman config nfc --disable openpgp
  ykman config nfc --disable hsmauth

  Check with:
  ykman info

- Set FIDO2 PIN (write down and store safely):
  ykman fido access change-pin

  Enroll FIDO2 method for disk encryption:
  sudo sdbootutil enroll --method=fido2
  
  Generate SSH keys (change application, name, comment and verify policy based on use and key):
  ssh-keygen -t ed25519_sk \
  -O resident \
  [-O verify-required] \
  -O application=ssh:personal-forges \
  -O user=mm-personal-forges-primary \
  -C 'Personal: forges -- Primary YubiKey' \
  -f ~/.ssh/mm_ed25519_sk_personal_forges_primary
  
- Change PIV management key to type supported by age-yubikey-plugin:
  ykman piv access change-management-key -a TDES --protect


  Change PIN:
  ykman piv access change-pin
